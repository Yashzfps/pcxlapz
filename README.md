# Rias Desktop Assistant

Rias is a text-based Python desktop assistant focused on:

- Web search Q&A (concise answers, not just links)
- Windows app launching (`open notepad`, `open chrome`, etc.)
- Gmail email sending with OAuth
- Persistent note taking (`note this down ...`, `show notes`)
- Sweet anime-style responses in every reply

## Quick Start

1. Install Python 3.8+
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. (Optional for email) complete Gmail setup in `setup_gmail.md`
4. Start Rias:

```bash
python main.py
```

## Command Examples

- `open notepad`
- `note this down buy groceries on sunday`
- `show notes`
- `send email to friend@example.com | Hello | How are you?`
- `latest cricket score india vs australia`
